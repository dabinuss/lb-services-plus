# Services+

Services+ is a custom FiveM LB Phone app resource.

## Project Instructions

Before working on this project, always read and follow:

1. `AGENTS.md`
2. `FiveM_LB-Phone_Development_Guidelines.md`
3. `ServicesPlus_Complete_Development_Plan.md`

The guidelines define the mandatory technical standards. The development plan defines the Services+ product scope, architecture, compatibility requirements, testing requirements and release criteria.

All code and technical documentation must stay consistent with these documents.
